# 阶段 1 只读读取层映射

更新时间：2026-07-23

这份表只描述已经落地的读取层，不把目标页面或未来自动策略写成当前能力。

| 工作台字段 | 当前来源 | 当前语义 | 已接入位置 |
|---|---|---|---|
| 行情来源 | `settings.json / last_data_source` | `计划`：用户配置，不等于连接成功 | 主窗口只读状态条 |
| 行情连接 | 数据源对象的连接状态 | `已确认`：当前对象的本地连接标记 | 主窗口只读状态条 |
| 品种、周期 | 数据源实际订阅；没有实际订阅时读取 settings 配置 | 实际订阅为 `已确认`，配置值为 `计划` | 主窗口只读状态条 |
| Worker 状态 | `execution-control.sqlite3 / worker_heartbeats` | `已确认`：本地心跳状态；心跳陈旧会明确显示 | 主窗口只读状态条 |
| Worker 心跳 | `last_seen_at` | `已确认`：新鲜或陈旧 | 主窗口只读状态条工具提示 |
| 券商对账 | `last_successful_reconcile_at` | 有成功时间后显示新鲜/陈旧；没有首次成功时间为 `未知` | 主窗口只读状态条 |
| 账户快照 | `records/execution.sqlite3 / account_snapshots` | 有持久快照为 `已确认`；没有快照为 `未知`，不伪造实时余额 | 主窗口只读状态条 |
| 活动执行数量 | `records/execution.sqlite3 / list_active()` | `已确认`：本地账本记录数量 | 主窗口只读状态条 |
| 最近执行状态 | `records/execution.sqlite3 / list_recent()` | `计划`：本地生命周期状态，不等于券商已确认成交/持仓 | 主窗口工具提示 |

## 明确未纳入当前读取层

- PA 分析结果、监督结论、订单明细、成交明细、保护单明细和生命周期聚合尚未形成统一 Read Model。
- 自动策略状态、加仓、减仓、反手、动态杠杆和关闭 GUI 后继续运行仍是 `规划中`，不能在页面上显示为“运行中”。
- 当前读取层只读已有对象和 SQLite 查询，不调用数据源网络接口，不创建执行计划，不入队命令，不连接券商写入适配器。

## 语义规则

- `已确认`：读取层确实观察到的本地状态，或 Worker 已保存的账户快照；来源和采集时间必须可追溯。
- `计划`：配置值或本地执行计划/生命周期状态；不能文案化为“已成交”“已持仓”或“保护已建立”。
- `规划中`：后端状态、权限或验收尚未交付的目标能力；当前实现只保留语义枚举，不显示可执行按钮。
- `未知`：没有足够证据，或首次对账尚未完成；不得用绿色成功状态替代。
