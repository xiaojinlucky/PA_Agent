## 本地 Codex 执行回传格式

本地 Codex 回传给网页版 GPT 时，必须附：

- 当前 checkout 路径、分支、HEAD、上游和工作区混合边界。
- 本次实际修改文件清单；未修改文件不能写成修改。
- 测试通过/失败数量和失败原因；超时不能算通过。
- 运行态、API/券商和远程 SHA 的独立证据。
- staged snapshot 密钥扫描、大文件/文件类型检查和提交/推送状态。
- 尚未完成和不能证明的事项。
- 本次审核结论、下一张工单、硬验收结果和是否允许继续 Demo 运行。
