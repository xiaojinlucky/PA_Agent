# PA_Agent — 问题、需求、修改意见与完成记录

## 1. 用户目标

- 安装并按原项目能力配置 PA_Agent，先用于黄金研究。
- 增加 Longbridge 行情数据源。
- AI 模型设置支持保存多套模型、真实连接测试与快速切换，并适配不同模型的 Thinking、推理强度和参数能力。
- 增加 Longbridge 模拟/综合/日内三档与 OKX 现货/永续的安全执行层，优先验证黄金但不硬编码品种。
- 项目内容、规则、需求和验证证据提交到私有 GitHub，供网页版 GPT Pro Extended Thinking 通过 GitHub 读取；网页版 GPT 充当总控和大脑，输出工单队列与硬验收。

## 2. 用户明确修改意见

- 安装配置阶段先保持原项目能力；原项目不能实盘时，不要假装已经可以实盘。
- PA 的全部前端重设计已经废弃；后续聚焦交易本身。
- “OKX 目前做 XAUUSD”表示优先搭建黄金现货类产品与永续，不是永久拒绝其他品种。
- API 凭据专门用于本机项目，可以写入仓库外环境文件，但不得进入 Git。
- Longbridge 现阶段优先使用有充足模拟资金的 paper account；综合与日内实盘档案继续保留并支持快速切换，但不能跨模拟/实盘自动回退。
- PA_Agent 必须作为独立项目维护，不与其他量化项目统一交付或共享执行层。
- 外部模型看不到本机 skills 与 memory；其计划必须由本地 Codex 按真实环境修订后才能执行。

## 3. 已发现的问题与边界

### 当前代码

- `AnalysisRecord` 是分析记录，不包含完整券商、账户、产品类型、数量、杠杆、TIF 和客户订单号。
- `trade_logger.py` 是交易机会记录，不是强一致订单账本。
- Longbridge 行情源只创建 `QuoteContext`；交易执行层按账户 Profile 独立创建交易/账户上下文。
- demo/replay 会经过部分真实分析信号路径；未来执行层必须双重阻断。
- 连接探测使用界面截止时间和单一在途槽位；第三方 SDK 若永久忽略超时，可能需要重启应用清理。
- 特殊半日市缺乏可靠提前收盘时刻，K 线闭合状态仍有边界。

### 实盘安全

- Longbridge 日内子账户的标的可用性和融资能力动态变化，不能用静态名称判断。
- Longbridge 模拟账户与实盘共用 App Key/Secret 但使用独立 Access Token；模拟账户不支持美股盘前盘后，撮合和现金规则也不能当作实盘等价验证。
- Longbridge 不能只凭环境变量前缀判断账户；三档 Token 必须同时通过模拟/实盘类型和绑定账户 ID 校验，界面未保存的路由变更必须停用并阻断所有写操作。
- 日内子账户只允许在“明确不支持/可购数量为零且确认没有订单受理”时回退综合账户；超时、未知、已受理或部分成交时禁止跨账户重发。
- OKX 黄金现货候选 `XAUT-USDT` 是代币化黄金，不等于传统 XAUUSD 现货。
- OKX 黄金永续候选 `XAU-USDT-SWAP` 的规格必须在下单前动态读取，不能长期硬编码。
- OKX Passphrase 尚缺；账户/持仓模式、当前杠杆和真实可交易数量必须在私有只读预检中确认。程序不自动修改模式或杠杆。
- 现有 OKX Key 的提币权限和 IP 限制不符合最小权限实盘标准，启用前必须整改。
- 网页版 GPT 与本地首轮审查共同发现 8 个执行阻塞：停用/在途写竞态、OKX 不确定 HTTP 被误判为确定拒绝、活动执行只绑定档案名而非实际账户、异常最大数量触发错误回退、跨进程活动路由竞争、终态成交数量缺失被当作零、非入场写在券商接受后崩溃会重发、账户可用资金与币种映射错误。
- 修复上述问题后的三线程对抗审查又发现 8 个阻塞：执行阶段撤单拒绝误终结活动记录、旧活动记录缺实际账户身份仍可读资金、写成功后本地保存失败可在同一运行实例重发、Longbridge 余额币种选择不严、终态缺成交量/明细被当成零、部分缺价生成虚假均价或盈亏、OKX 私有身份读取前未校时，以及入场结果未知时 UNKNOWN 状态保存失败未先停写。

### 验证

- 新执行域定向测试、相邻回归与严格落盘集成测试均有退出码 0 的独立汇总；当前主线程执行相关 9 文件为 201 通过 / 0 失败，全量 unit 为 931 通过 / 28 个既有非执行域失败，精确证据见 `CONTEXT.md` 与 `docs/VALIDATION_EVIDENCE.md`。
- `compileall` 与执行域定向 Ruff：通过。
- 原有 Qt E2E 单测仍会超时且没有最终汇总；不能宣称全仓/E2E 通过。

## 4. 已完成修改

- Longbridge 只读行情源、Token 状态和数据源工厂接入。
- 数据源事务式切换、每数据源独立品种与连接状态。
- 多套 AI 模型档案保存、真实连接探测、原子切换。
- 不同提供商的 Thinking、推理强度、上下文与兼容参数适配。
- 自由追问会话生命周期与部分超时/取消处理修复。
- 凭据、配置、日志、记录和临时目录的 Git 忽略与安全钩子。
- `CONTEXT.md`、`lessons.md`、移交说明和验证证据。
- 严格原子分析记录落盘与落盘内容复核；演示/失败/短路/低置信度/品种不匹配阻断。
- SQLite 执行账本、唯一客户订单号、意图先落盘、提交未知只读对账、重启恢复和会话停写。
- Longbridge 模拟/综合/日内独立凭据与快速切换；模拟账户和实盘隔离，日内到综合安全回退，覆盖部分成交、原生止损、软件止盈、主动离场和账户总盈亏。
- OKX 通用现货/永续动态规格、持仓模式/杠杆只读检查、OCO 保护、主动离场、永续 `fillPnl` 与账户资金/持仓。
- 三条完整模拟生命周期：OKX 永续、OKX 现货、Longbridge 日内不足回退综合账户。
- 8 个执行阻塞已按本地架构收敛修复：会话写门线性化、OKX POST 不确定状态、实际账户非密钥指纹、严格额度解析、SQLite 原子路由占用、终态成交明细核验、运行实例级防重发标记，以及 Longbridge/OKX 官方资金字段和目标币种映射。
- 对抗审查新增的 8 个阻塞已修复：拒绝后保留活动监控、旧记录身份补验、所有可能已写操作的 fail-closed 保存、Longbridge 同币种资金边界、终态数量未知、缺价不伪造均价/PnL、OKX 私有读取前校时，以及入场 UNKNOWN 保存失败时停写并轮换 runtime。
- 已加入多进程争抢、线程竞态、进程中断、字段缺失、响应乱序与账户切换的故障注入测试；测试不访问券商写接口。
- 三个独立只读审查线程最终均确认 PASS，阻塞落地的问题为 0；7 个核心并发/崩溃用例连续 10 轮共 70 通过 / 0 失败。

## 5. 尚未实现

- OKX Key 最小权限整改：移除提币权限并确认 IP 白名单。
- Longbridge 实盘可交易验收：综合与日内账户当前 GLD.US 最大数量均为 0；模拟账户只读容量验证已通过，但尚未发送模拟订单。
- 最小受控实盘 Canary；必须在上述阻塞清零后由用户对具体订单另行授权。

## 6. 当前交付原则

用户手动启动网页版 GPT Pro Extended Thinking，让它通过 GitHub 读取并提出需求冻结、总控路线图、工单和硬验收；本地 Codex 再根据实际 skills、memory、代码、环境和测试结果进行适配。未经本地适配、用户确认与独立审查，不直接按外部工单修改代码或启用实盘。
