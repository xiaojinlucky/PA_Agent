4. 关键交互流程
4.1 市场切换
同一 Longbridge 内切换 US、HK、CN

用户选择目标市场。

selection_generation 加一，创建 staged selection。

页面保留旧 committed 市场、标的、报价和图表。

校验目标市场与标的后缀。

在工作线程中请求静态信息、目标订阅、首份报价和首份已收盘 K 线。

所有结果均校验 generation、完整身份及各自 request sequence。

连接、标的、周期、静态信息、首份报价和首份 K 线全部通过后，主线程一次性提交不可变页面快照。

提交完成后停止旧订阅。

任一步失败则释放 staged 资源。

旧状态仍可证明有效时继续显示旧状态，并在对应证据组显示切换失败。

旧状态恢复也失败时清空不能证明的报价与 K 线，进入切换失败。

US、HK、CN 切换不得断开并重新建立 Longbridge 全局连接。

Longbridge 与 OKX 跨源切换

创建由工作线程拥有的独立 staged source。

staged source 完成连接、认证、静态信息、订阅、首份报价和首份已收盘 K 线。

旧 committed source 在提交点前继续运行。

全部门禁通过后，由主线程一次性提交新状态。

提交成功后释放旧 source。

旧 source 释放失败只记录资源错误，不回滚已验证的新状态。

旧 source 后续回调必须失效。

新 staged source 失败或被更高 generation 取代时，只释放 staged source，不断开 committed source。

Longbridge 全局认证失效

Longbridge 全局认证失效优先于普通回滚。

立即清空当前和暂存的 US、HK、CN 报价。

取消三个股票市场的待提交状态。

禁用相关分析。

不得回滚到同一失效认证下的旧 Longbridge 页面。

已独立验证的 OKX Crypto 状态不受影响。

4.2 标的与周期切换

用户点击自选行或通过当前标的入口提交标的。

标的必须先规范化，并通过市场后缀校验。

用户切换 10m、1h 或 4h 时，同样视为新的选择组合。

每次正式提交市场、标的或周期组合，generation 加一。

切换中继续显示旧 committed 标题、报价和图表。

新状态通过全部门禁后一次性替换。

标的不支持或周期不支持时，不猜市场、不换源。

分析中禁用市场、标的和周期控件，只保留取消分析。

4.3 本地自选
添加

用户触发「添加自选」。

输入值规范化并校验当前市场。

合法且未重复时追加至当前市场列表。

递增 watchlist_change_sequence 和 settings_change_sequence。

不递增 selection_generation，除非用户同时选择该标的。

启动有界自选行情刷新。

排队保存四市场完整设置快照。

移除

用户触发「移除自选」。

从当前市场列表移除。

已删除标的的在途结果全部失效。

移除当前选中标的时，中央已提交标的保持不变，只取消其自选成员身份，不发生隐式切换。

不删除历史分析记录。

递增自选和设置序号并排队保存。

排序

使用拖动手柄调整用户顺序。

排序只改变本地设置，不改变当前标的。

不按涨跌、名称或价格自动排序。

同一 generation 内连续排序只允许最新完整设置快照清除未保存。

4.4 刷新行情

刷新当前标的报价、静态信息和 K 线时，各请求族分别递增 request sequence。

同一选择刷新不增加 generation。

同一来源已有自选刷新周期在途时，不再启动第二个并发周期。

可取消的旧请求取消，不可取消的结果依靠序号丢弃。

刷新按钮保持「刷新行情」，只改变图标和禁用状态。

传输失败不修改原行情时间。

同身份存在最后权威快照时显示行情已过期。

从未获得有效快照时显示行情不可用并清空数值。
