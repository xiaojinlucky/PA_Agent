## 证据口径

- **代码存在**：只说明实现已经进入仓库。
- **测试通过**：只说明确定性测试覆盖的行为通过。
- **外部只读验证**：说明真实数据源读取成功，不等于交易可用。
- **离屏界面验证**：说明固定夹具下的界面结构、状态和尺寸通过，不等于真实桌面验收。
- **运行态验证**：必须来自当前进程、当前完整 Git SHA、当前数据库版本和新鲜券商只读事实。
- **稳定发布**：只有能力索引所有适用层均为 `verified`，且
  `stable_release_ready=true`，才允许创建稳定 tag 和 GitHub Release。
